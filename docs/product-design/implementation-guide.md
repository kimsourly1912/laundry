# Laundry implementation guide

| Screen | Current behavior |
| --- | --- |
| Fill slip | Show the assigned paper slip on the owner home page. Tap its fields, then save once. |
| Saved slip | Show the saved artwork and Telegram QR. New slip opens the next blank copy. |
| Saved slips | Search and reopen previous slips. |
| Platform | Create the shop, check its template in Studio, then publish and assign. |

Use the [plan](../plan.md) for failure states and implementation checks, the [pilot walkthrough](../city-laundry-pilot-plan.md) for the real counter test, and the [Studio reference](../html-template-studio-plan.md) for template authoring.
